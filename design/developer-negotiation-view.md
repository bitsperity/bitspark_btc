## Key Features

1. **Clear Thread View**
   - Chronological display of offers and counter-offers
   - Each offer shows key details (bid, start date, duration)
   - Current status clearly visible

2. **Action Buttons**
   - Primary actions prominently displayed
   - Accept/Decline/Counter options for current offer
   - Context-aware button states

3. **Job Context**
   - Job title and owner always visible
   - Key requirements easily accessible
   - Important dates and deadlines shown

4. **Navigation**
   - Easy access to other jobs and sections
   - Clear indication of current section

5. **Status Indicators**
   - Current negotiation status
   - Time indicators for all actions
   - Visual thread progression
